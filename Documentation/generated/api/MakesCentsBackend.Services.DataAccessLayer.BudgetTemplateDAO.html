ApplyBudgetTemplateWithinTransactionAsync(ApplyBudgetTemplateRequest, MySqlTransaction)

Core logic for applying a template to a budget month, runs inside a transaction the CALLER owns (doesn't commit/rollback itself) - so it can be reused by BudgetDAO to make "create a budget month" and "apply its template" one atomic operation. This ALWAYS fully replaces that month's existing funding queue - it does not merge with or preserve whatever was there before. Records which template was applied on budget_month.budget_template_id.

SetBudgetTemplateEnvelopesAsync(SetBudgetTemplateEnvelopesRequest)

DAO method to set (create/reorder/update/remove all at once) a template's envelope entries. Existing rows not present in the incoming list are deleted. Rows with a BudgetTemplateEnvelopeId are updated in place Rows without one are inserted new. order_index is reassigned by each item's position in the incoming list - kept rows are first bumped into a high temporary range before being written back to their final low value, since unique_template_order is checked immediately (not deferred) and a straight reorder could otherwise collide with another row's still-current value. Also enforces that the same envelope can't appear twice in one template (unique_template_envelope_sinking / unique_template_envelope_rollover).
