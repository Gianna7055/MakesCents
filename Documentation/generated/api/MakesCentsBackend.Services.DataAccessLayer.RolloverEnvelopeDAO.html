Namespace
MakesCentsBackend.Services.DataAccessLayer

MakesCentsBackend.dll

Data access object for rollover envelopes. Rollover envelopes are split across two tables:

  • rollover_envelope: the persistent definition (name, category, default transfer target). No dollar amounts live here since a rollover envelope isn't guaranteed to be active every month.
  • rollover_envelope_month: the amounts for one specific month. Absence of a row here means the envelope wasn't activated that month. Most "get/update amount" operations need a budget_month_id in addition to the envelope id.

GetOrActivateForMonthAsync(int, int, MySqlTransaction?)

DAO method to get (or create, if not yet activated) this month's instance of a rollover envelope. Called when a budget month is first being set up, or the first time a transaction split needs to point at this envelope for a given month. No longer takes a planned amount - that now lives on envelope_funding, not here - so a newly activated month just starts at its table default remaining_amount of 0.
