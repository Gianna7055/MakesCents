Class EnvelopeFundingEntityModel

Namespace
MakesCentsBackend.Models

MakesCentsBackend.dll

Model for a single envelope funding row - one envelope's planned funding amount and priority order for a specific budget month. This is a plan, not a money movement - actual money still moves into envelopes via transactions. EnvelopeId is a display/API-level id - IsSinkingFund says whether it refers to a sinking_fund_envelope_id or the persistent rollover_envelope_id (not the month-specific rollover_envelope_month_id, which is an internal DAO detail).
